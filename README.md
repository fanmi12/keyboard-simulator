# 键盘输入模拟器

绕过网页粘贴限制，自动模拟逐字键盘输入。

## 安装（只需一次）

1. 打开 [keyboard-simulator.html](https://fanmi12.github.io/keyboard-simulator/keyboard-simulator.html)
2. 把页面上的蓝色按钮**拖到浏览器书签栏**
3. 完成

## 使用

1. 在任意网页点击书签栏的 **⌨️ 模拟键盘输入**
2. 在弹出的编辑面板中粘贴你要输入的文字
3. 点击 **"开始输入"**
4. 倒计时期间点击目标输入框
5. 倒计时结束后自动逐字键入

## 功能

- 可调节打字速度（随机间隔）
- 可调节倒计时秒数
- 支持 `<input>`、`<textarea>` 和 `contenteditable` 元素
- 模拟完整的键盘事件（keydown/keypress/input/keyup）
- 编辑面板可拖拽移动
- 无需 F12 控制台，无需任何技术操作
